# 非營利園財報抽取作業規範

抽取用的作業指示。派工時只需給代號、學年度與影像目錄，其餘依本文件執行。

## 為什麼規則這麼嚴

這些數字會用來決定政府稽查的優先順序。**一個錯誤的數字可能導致對合法幼兒園的
錯誤指控。** 因此：**準確性遠重於完整性，絕不猜測數字。**
回報缺漏讓人工補是正確的；產生一個看起來合理的錯誤數字不是。

## ⚠️ 步驟零：先建立你自己的私有工作目錄

**多份報告是同時抽取的。若你把裁切圖寫到共用暫存路徑，其他 agent 會覆蓋你的檔案，
你就會讀到別的幼兒園的頁面。** 這已經真實發生過兩次
（一次裁切圖顯示的是 中園／成長文教基金會，而該 agent 抽的是 中平）。

把數字歸到錯誤的機構，是本管線最嚴重的錯誤——比看錯一個數字嚴重得多，
因為後續每一項合規發現都會指名錯誤的園。

因此：

1. **建立以你的報告代號命名的私有目錄**，例如
   `/tmp/extract_N16_中平_113/`，所有裁切與中間檔案只寫在裡面。
2. **每次讀取頁面前，先確認頁尾代號。** 每頁頁尾印有 `<代號>-<頁碼>`
   （例如 `N16-5`）。**代號不符就是拿到別園的檔案，立刻停止並重新複製。**
3. 裁切前可比對檔案大小與原始 PNG 是否一致，作為第二道保險。

## 步驟一：辨識頁面

影像目錄裡是 `p04.png` 起至該報告最後一頁（檔名數字＝報表印刷頁碼）。
**用頁尾代號辨識歸屬、用表頭辨識報表種類**——各報告頁數 30–49 不等，
附註長度不一，不可靠位置推定。

要找三頁：

1. **資產負債表**
2. **收支餘絀表（本期）**——通常有兩頁，本期與比較期。
   本期是「該學年度 8/1 至次年 7/31」。**選本期那頁並記下頁碼。**
   （新設園可能從開辦日起算，例如 111.9.30~112.7.31，仍屬本期。）
3. **財務報表附註 一、一般概況**——是敘述文字，不是表格。
4. **財務報表附註 二、重大會計政策**——**全節逐字轉錄**，見下方說明。
5. **財務報表附註 三**（若有）——`其他收入`／`其他支出`的組成明細。
6. **財務報表附註 五**（若有）——**關係人交易**，揭露付給受託法人的金額。

⚠️ **附註二要抄原文，不要只抄你認為重要的部分。** 所有法遵檢核的判準都出自這一節
（(一)所得稅、(四)資遣費準備、(五)業務發展準備提列上限、(六)、(八)不得淨額入帳、
(十)人事費不得流出），而條文措辭**未必每份報告都相同**——昌福 110 的附註二(五)
明定「收入總額（家長繳交之費用；其有政府差額補助費者，應合併計算）」，
先前因未抽原文，檢核一直誤用收支餘絀表的「收入合計」當分母。

原文留著，日後怎麼分析都能重來；原文沒留，判準改了就得重抽整份報告。

⚠️ **第 4、5 項的位置不可推定，且標題未必叫「附註三」「附註五」。**
113 學年度多在 p12–p16，但 N01 安溪 110 在 **p19、p21**；且 110 學年度的報告
不使用獨立的附註編號標題，同樣內容併在「三、重要會計項目說明 (四)收支明細表」
與「五、關係人交易」之下。

可靠的做法是**用收支餘絀表的附註欄代號回查**：該表各科目右側標的「三」「五」
就是指向這兩節。影像目錄含該報告 p04 至最後一頁的全部頁面，往後翻到底再下結論。
**找不到就填 null 並在 `issues` 說明找過哪些頁，不要猜。**

為什麼要這兩個附註：

- **附註三**：多份報告的 `其他收入` 與 `其他支出` 金額**完全相同**
  （佔收入 10–24%），而附註二(八) 明文「不得以收支相抵後淨額入帳」。
  是否真的總額入帳，只有附註三答得出來。
- **附註五**：中園 113 學年度的附註五只揭露給受託法人的行政管理費 203,350 元，
  但收支餘絀表列 311,956 元，**同一份報告內差 108,606 元**。
  這類報表與附註互相矛盾的情形基準率天然很低，比全體共同的行為有價值得多。

`note_3` 與 `note_5` 若該報告沒有對應附註，整個物件填
`{"page": null, ...}` 並在 `issues` 說明，**不要用其他附註的內容填充**。

`note_2.text` 是**逐字轉錄，不是摘要**。看不清的字用 `□` 標記並在 `issues` 說明，
不要改寫、不要省略你認為不重要的款次——判斷哪一款重要是分析，不是抽取。

`income_statement.lines` 要收錄**所有**收入與支出科目，加上 `收入合計`、`支出合計`、
本期餘絀相關列。最關鍵的支出科目：
`人事費`、`業務費`、`材料費`、`維護費`、`修繕購置費`、`雜支`、`行政管理費`、`業務發展費`。

## 硬性規則

1. **空白格填 `null`，絕不填 `0`。** 破折號（—、-、`$ -`）也是空白。
   支出科目的預算數空白代表「未編列預算」，是稽查發現；填 0 是對機構捏造財務陳述。

2. **括號是負數**：`(215,209)` → `-215209`。百分比同理：`(2)` → `-2`。

3. **資產負債表只取左側（本期）欄。** 右欄是比較期（前一年度）。
   並記下左欄的基準日——**學年度 N 的基準日是 (N+1)/7/31**，
   例如 113 學年度的資產負債表主要欄位是 114/7/31。

4. **`$` 是幣別標記，不計入數值。**

5. **逐字照抄項目名稱**，保留名稱內的全形空白（如「合　　計」），
   但**去掉行首的階層縮排空白**。

6. **紅色關防會壓住表頭。** 用色彩通道分離（取 R 通道或 max-of-RGB）可讓
   底層黑字清晰可讀。宣告任何東西無法辨識之前先試這個。

7. **⚠️ 低解析度整頁判讀不可信。** 已有多次紀錄：整頁低解析度的第一次判讀
   產生了看似合理但完全錯誤的數字。**每個數字都要從放大裁切（3–4 倍）確認**，
   再用步驟三的驗算交叉檢核。

8. **形近字已定案，不要重新判讀。** 附註二固定出現三組字，全部驗證過：

   | 正確 | 常見誤抄 | 出現處 |
   |---|---|---|
   | **賸**餘款 | 膡、膸 | (十)10、(十一)標題及款內 |
   | 累積餘**絀** | 餘紐 | 資產負債表、收支餘絀表、附註二 |
   | **倘**有不足 | 尚 | (十)3(2)、(十)5(2)、(十)8 |

   ⚠️ **不要用「左偏旁是月還是貝」去分辨賸／膡——這個判準是無效的。**
   「賸」＝朕＋貝＝**月＋关＋貝**，左偏旁本來就是「月」，貝在右側；
   「膡」＝月＋朕＝月月关。要看的是**右下角有沒有「貝」的分叉兩腳**。
   曾有 11 份報告的 agent 各自用錯誤判準得到同一個錯字，並在 `issues` 寫下
   「已放大 8–18 倍確認為月部」——放大倍率再高，判準錯了還是錯的。
   已於 N24 佳林 110 p13、N33 淡海 113 p14 以 12 倍放大定案，
   且所引法源（非營利幼兒園實施辦法第三十四條）用字即為「賸餘款」。

9. **看不清就填 `null` 並寫進 `issues`。絕不猜。**

## 步驟三：交件前自行驗算

不通過就回去重讀，**不要交出自己知道加不起來的數字**：

- `流動資產合計` = 各流動資產項目之和
- `資產總計` = `流動資產合計` + `非流動資產合計`
- `資產總計` = `負債總額` + `餘絀總額`
- `餘絀總額` = `累積餘絀` + `本期餘絀`
- `收入合計` / `支出合計` = 各科目決算數之和
- 各科目 `執行率` ≈ `決算數 / 預算數`（表上四捨五入到整數）

可用的額外交叉驗證來源：`淨值變動表`、`現金流量表`（通常在資產負債表後 2–4 頁）。
現金流量表的期末現金應等於資產負債表的現金及銀行存款。

## 常見的版面變異（都遇過，不是錯誤）

- **新設園只有單一期間欄**，無比較期，`累積餘絀` 為空白。**不要憑空造出比較欄。**
- **沒有 `本期餘絀` 這一列**，而是分成 `本期稅前餘絀` / `所得稅費用` / `本期稅後餘絀`。
  照抄，不要合併成一列。
- **附註常把核定與實際招收人數印成一個合併數字**（如「核定及實際招收總人數：120 名」）。
  此時兩個欄位都填該數字，並在 `issues` 說明是合併陳述。
- **部分科目在某些年度不存在**（如 `業務發展準備金`、`公共事務管理費`）。
  填 `null` 並在 `issues` 註明「本表無此科目」，
  以區別「這份表沒有這一列」與「我漏抄了一列」。

## `issues` 欄位要寫什麼

這一欄是**產出的一部分，不是免責聲明**。過去的抽取在這裡發現了
我們原本沒設計的訊號，例如：

- 資產面準備金與負債面準備金金額不符，且與該報告自身的附註說明矛盾
- 附註的核定人數與官方登記資料差距極大
- 報表 `差異數` 欄本身存在 1 元的四捨五入誤差
- 附註五揭露數與**年末應付受託法人餘額**不符（見下方，多數報告兩者相等，
  不符才值得寫）
- 現金流量表的投資活動為破折號，但非流動準備金資產確實增加
  （即：提列了準備，但看不到存入專戶的現金流出）

**看到文件內部矛盾就寫進來，並明確區分「文件本身不一致」與「我可能看錯」。**

⚠️ **不要把「全體都這樣」當成發現。** 已知下列行為在本語料庫中**普遍存在**
（92% 以上），寫進 `issues` 沒有意義，只會淹沒真正的異常：

- 行政管理費執行率恰為 100%（契約固定管理費）
- `業務發展費`／`延長照顧服務支出`／`其他支出` 未編列預算
- 人事費執行率低於 100%（34/37 份如此）
- 附註把核定與實際招收人數印成一個合併數字
- **附註五揭露數 ≠ 收支餘絀表列示的行政管理費**（47 份中 45 份如此——
  揭露數是**年末應付受託法人餘額**，不是全年費用，兩者本來就不該相等。
  這是我們自己踩過的坑：中園 113 曾把這個差額誤判為報表矛盾，
  比對全語料庫後才發現差額 = 當年度已現金支付金額，是正常關係。
  真正值得寫的是**揭露數與年末應付款餘額本身不符**）

值得寫的是**同一份文件自我矛盾**、**與官方登記資料不符**、
或**與該報告自述的會計政策不符**的情形。
