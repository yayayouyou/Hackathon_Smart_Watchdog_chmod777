# 02 — 鑑識會計訊號設計書

命題要求「AI × 鑑識會計」。這份文件把「鑑識會計」從口號變成**可計算的欄位**。

所有範例數字取自實測的 N01 安溪非營利幼兒園 113 學年度財報
（資產負債表基準日 114/7/31 與 113/7/31；收支餘絀表期間 113.8.1–114.7.31 與 112.8.1–113.7.31）。

---

## 0. 先講一個重要的方法論前提

非營利幼兒園的會計基礎是**成本分攤制**（家長＋政府共同分攤核定營運成本），
不是營利事業。因此若把上市公司的財務比率直接搬過來，會產生大量假警報。例如：

- 餘絀（盈餘）接近零**是制度設計的結果，不是經營不善**。
- 負債占資產比 99% 看起來危險，但其中大部分是「業務發展準備」「應付代管財產」
  等**指定用途科目**，不是外部借款。

→ 所有比率都必須**在同儕群組內做相對比較（z-score / 分位數）**，
   而不是套用通用門檻。且**公立園與非營利園必須分群**（財源結構完全不同，見 01 文件）。

這一點會直接寫進模型，也是簡報時對評審展現專業度的關鍵區隔。

---

## 1. 最強訊號：預算執行率（Budget Execution Variance）

非營利園的收支餘絀表**直接印出「預算數 / 決算數 / 差異數 / 執行率%」**。
這是絕大多數財務資料集沒有的東西——它讓我們可以問：
**「錢核定了，但實際花在哪裡？」**

### 實測 N01 安溪 112 學年度

| 科目 | 預算數 | 決算數 | 執行率 | 解讀 |
|---|---|---|---|---|
| 人事費 | 13,414,768 | 11,797,585 | **88%** | 少花 162 萬在人身上 |
| 業務費 | 883,400 | 394,450 | **45%** | |
| 材料費 | 2,375,920 | 2,216,621 | 93% | 正常 |
| 維護費 | 143,000 | 51,581 | **36%** | |
| **修繕購置費** | 190,400 | 28,074 | **15%** | ⚠️ 幼兒園設施幾乎沒修 |
| 雜支 | 53,004 | 18,950 | 36% | |
| **行政管理費** | 325,932 | 325,932 | **100.0%** | ⚠️ 給受託法人的錢，分毫不差全收 |
| 業務發展費 | — | 2,388,000 | — | ⚠️ 無預算卻支出 239 萬 |

### 為什麼這是紅旗

**`RED-01 設施維護遞延（Deferred Maintenance）`**
修繕購置費執行率 15%、維護費 36%。這不是財務問題，是**兒童安全問題**：
遊具、消防、門禁、廚房設備該修沒修。這條訊號的價值在於它能被稽查人員
**立刻行動**（排實地安全檢查），而不只是一個抽象分數。

**`RED-02 關係人費用優先支付（Related-Party Priority）`** — ❌ **已被實測推翻**

> ⚠️ **本項判讀錯誤，保留原文以記錄修正過程。詳見
> [05-phase1-results.md](05-phase1-results.md) §10.3。**
>
> 原推論：「所有科目都少花，唯一 100.0% 精準執行的是付給受託法人的行政管理費。
> 該花在小孩身上的少花，該付給法人自己的全付——典型的資源排擠型態。」
>
> **實測 18 所非營利園的行政管理費全部是 100%。** 它是委託契約的固定管理費，
> 足額執行是制度常態，不是異常訊號。以此為紅旗會對全部非營利園發出警報。
>
> `related_party_priority`（行政管理費執行率 − 其他科目平均）在 9 案例 vs 9 對照
> 的配對檢定中**方向與預期相反**（案例 0.219 vs 對照 0.352）。
> 此指標實際測量的只是「其他科目少花多少」，與關係人無關。
> **降級為不計分。**

**`RED-03 無預算支出（Off-Budget Spending）`** — ❌ **已被實測推翻**

> ⚠️ 原推論：業務發展費 2,388,000 元預算數空白，「無預算科目出現大額支出，
> 應調閱動支依據」。
>
> **實測 18 所幾乎全部都有無預算的業務發展費／延後托育支出／其他支出。**
> 這是非營利園的普遍會計慣例（年度中依實際需要動支指定用途資金），
> 不是異常。**降級為不計分。**

**`RED-04 人事費短編＋滿招 → 師生比疑慮`**
人事費只執行 88%（少 162 萬），但招收率 118/120 = 98%。
**滿招卻少發薪水**，兩種可能：編制未補足（違反師生比）或薪資低於行情（高流動率）。
兩者都是教保品質風險。這條要與附註的教保人員數交叉驗證（見 §3）。

## 2. 倒閉預警：預收款 vs 現金（最重要的家長保護指標）

對家長而言最慘的情境是**惡性倒閉**——學費已繳，園突然關門。
資產負債表可以直接量測這個風險：

```
prepaid_coverage = 現金及銀行存款 / 預收款項
```

實測 N01 安溪：

| 基準日 | 現金 | 預收款項 | 覆蓋倍數 |
|---|---|---|---|
| 113/7/31 | 9,654,314 | 5,207,452 | 1.85× |
| 114/7/31 | 8,868,744 | 4,324,548 | 2.05× |

安溪安全（>1）。但**若某園覆蓋倍數 < 1，代表家長預繳的學費已經被花掉**，
一旦招生下滑就會斷鏈。這是本系統最有社會說服力的單一指標，
且**只需要兩個欄位**就能算——OCR 成本極低、可解釋性極高。

建議做成三級燈號：`≥1.5 綠 / 1.0–1.5 黃 / <1.0 紅`（門檻需用同儕分布校準）。

## 3. 法遵硬指標：師生比（可直接開罰，非軟性分數）

附註一「一般概況」提供 `實際招收人數` 與 `教保人員數`（安溪 113：118 名 / 12 人）。

《幼兒教育及照顧法》師生比上限：2–3 歲 **1:8**、3 歲以上 **1:15**。
（實作時需依各園實際年齡分班數調整，附註未必提供分齡人數 → 先算保守上界。）

```
staff_ratio = 實際招收人數 / 教保人員數
安溪 113: 118 / 12 = 9.83   → 若全為 3 歲以上（上限 15）則合規
```

這條的價值：**輸出不是「風險 0.73」，而是「疑似師生比不足，建議調閱編制表」**。
命題要的「讓稽查人力精準投放」，靠的就是這種可行動輸出。

衍生指標：
```
salary_per_educator = 人事費 / 員工人數
安溪 112: 11,797,585 / 18 = 655,421 元/人/年  → 同儕比較，過低 = 流動率風險
cost_per_child      = 支出合計 / 實際招收人數
安溪 112: 18,744,221 / 118 = 158,849 元/人/年 → 過高需檢視，過低疑品質不足
```

## 4. 準備金與淨值異常（需領域驗證後才可下結論）

實測安溪出現三個**值得追查但還不能斷言為弊端**的現象：

1. **本期餘絀由 +250,799（112）翻轉為 −1,988,771（113）** — 由盈轉虧近 200 萬。
2. **業務發展準備（負債）10,479,844 → 15,899,844**，成長 52%，且是在虧損年成長。
3. **準備金提列不足**：113 年「業務發展準備**金**」(資產) 13,699,844
   小於「業務發展準備」(負債) 15,899,844，差額 **2,200,000**。
   112 年兩者相等（皆 10,479,844）。

第 3 點是最值得追的：**指定用途負債未被對應資產完全覆蓋，缺口 220 萬**，
且缺口出現的年度正好是大額虧損的年度。這兩件事很可能是同一筆交易的兩面。

⚠️ **但這需要先確認非營利園的準備金會計慣例**，才能判斷是異常還是正常提列時序差。
   在確認之前，系統應標為「待人工判讀」，不可直接輸出為「疑似不法」。
   誤指一所合法幼兒園有弊端，對本系統的公信力傷害遠大於漏掉一所。

指標化：
```
reserve_funding_gap = 業務發展準備(負債) − 業務發展準備金(資產)
equity_erosion      = 餘絀總額本期 / 餘絀總額前期
安溪: 482,847 / 2,471,618 = 0.20  → 淨值一年掉剩 1/5
```

## 5. 跨文件一致性稽核（同時解決 OCR 可信度與重編偵測）

每份報表含**兩年比較數**。113 學年度報表中的 112 數字，
應等於 112 學年度報表中的 112 數字。

```
for 每個科目 x, 每個年度 y:
    a = extract(報表[y],   欄位=當期, 科目=x)
    b = extract(報表[y+1], 欄位=前期, 科目=x)
    if a != b:  → flag
```

差異的兩種解釋，處理方式不同：

| 情況 | 判別 | 處置 |
|---|---|---|
| OCR/LLM 抽取錯誤 | 差異隨機、金額零散 | 自動重抽該頁，仍不一致則送人工 |
| **追溯重編 restatement** | 差異成套、上下相加仍平衡 | **列為鑑識紅旗** `RED-05` |

這個機制的策略價值：評審一定會問「你們用 LLM 抽掃描檔，數字可信嗎？」
答案是**「我們有 132 份報表 × 兩年重疊，天然的雙盲對帳，
抽取準確率可被量化而不是靠嘴巴保證」**。這是本方案的防守核心。

## 6. 數字型態分析（Digit / Pattern Analysis）

抽完全部 132 份 × 約 30 個科目 ≈ 4,000 個金額後可做：

- **Benford 首位數分布**：對「決算數」欄做檢定。整體偏離不代表造假
  （小樣本、科目異質），但**單一園顯著偏離同儕**值得追。謹慎使用，
  簡報時要明確講清楚它的統計限制，不要當成鐵證。
- **整數尾數異常**：業務發展費 `2,388,000`、行政管理費 `325,932`。
  前者整千整百，後者與預算數完全相同 → 疑似「先決定金額再湊科目」。
  指標：`round_number_share = 尾數三位為 000 的科目數 / 總科目數`
- **恆等異常**：其他收入 `1,344,392` **完全等於**其他支出 `1,344,392`。
  可能是合法的代收代付，但也可能是資金過路。列為 `RED-06 待說明`。

## 7. 會計師層面訊號

- **查核意見類型**：非「無保留意見」即為強訊號（保留／否定／無法表示意見）。
- **事務所集中度**：若某一法人旗下多園都用同一小型事務所，獨立性風險上升。
  （安溪為誠明聯合會計師事務所）
- **簽證會計師更換**：連續年度換所，特別是換所後數字大幅變動 → 典型紅旗。
- **附註揭露長度**：附註頁數（30–49 頁不等）明顯少於同儕 → 揭露不足。
  這個特別好用，因為**不需要 OCR 就能算**（頁數已在 `pdf_survey.csv`）。

## 8. 公立園（決算書）對應訊號

公立園沒有「預算 vs 決算執行率」以外的家長預繳問題（87.5% 靠公庫撥款），
訊號組合不同：

```
gov_dependency      = 政府撥入收入 / 基金來源        板橋 113: 87.5%
tuition_shortfall   = 學雜費決算 / 學雜費預算        板橋 113: 84.4%  ← 招生不足代理變數
capex_execution     = 建築及設備計畫決算 / 預算      板橋 113: 96.3%
fund_balance_trend  = 期末基金餘額逐年變化          板橋: 2,927,106 → 4,257,923
```

`tuition_shortfall` 特別有用：學雜費收入低於預算 15.6%，
在「政府撥款照給」的結構下，這是**招生不足最乾淨的代理指標**
（公立園不公開招生數，但學雜費會誠實反映人數）。

員工人數彙計表 / 用人費用彙計表可比照 §3 算師生比與人均薪資。
