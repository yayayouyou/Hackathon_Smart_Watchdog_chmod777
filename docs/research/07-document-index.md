# 07 — 文件索引：今天要找的資訊在哪一份文件的哪一頁

主辦方給的是 **162 份 PDF、1.8 GB**。稽查員在決賽現場的問題長這樣：

> 「三多非營利幼兒園的業務發展準備金，資產面跟負債面差多少？我記得不只一年，
> 110 到 113 學年度各差多少？**請給我資產負債表的頁碼。**」

最後那句話決定了整個設計。

---

## 1. 為什麼不做向量檢索

「PDF 很多 → 丟進向量資料庫 → RAG」是這題的預設答案。在**這批**語料上它會壞掉，
三個理由都是硬的：

1. **132 份非營利財報是純掃描影像。** `fitz.get_text()` 回空字串。
   PDF 裡根本沒有文字可以嵌入——內容只存在於已抽取的結構化 JSON 裡。
2. **公校決算書有 218 頁（1.9%）文字層是 PUA 私有造字亂碼**，而且**每頁的
   對應表不同、無法解碼**。把亂碼嵌進向量空間，只會得到有自信的垃圾。
3. **稽查要的是可引用，不是相似。** 近似最近鄰給不出頁碼；而在這個場景裡
   **給錯頁碼比答不出來更糟**——稽查員翻到別的表，會認定系統在亂講，
   整套工具就失去信任。

所以這裡建的是**精確定位索引**：確定性、可複現、離線、每一筆都帶出處。
會場網路不通也照樣運作。

> 這不是說語意檢索沒有價值。它的位置在**問句理解**那一層（把「差多少」
> 對應到「資產面 − 負債面」），不在**證據取得**那一層。證據必須是精確的。

## 2. 結構

SQLite + FTS5，只用標準函式庫的 `sqlite3`。四張表各回答一種問題：

| 表 | 回答 | 筆數 |
|---|---|---:|
| `documents` | 這批語料有哪些文件？哪些是掃描影像？ | 148 |
| `sections` | 某個區段在哪一份文件的哪幾頁？ | 1,144 |
| `facts` | 某個數字是多少？出處在哪？ | 11,448 |
| `passages` | 哪些文件提到某段文字？（FTS5） | 4,306 |
| `coverage` | **這個索引不知道什麼？** | 6 |

索引檔 8.4 MB，`python run.py doc-index` 重建。

### 內容從哪裡來

**不是從 PDF**，而是從已經抽取／盤點過的產物——因為 PDF 裡沒有文字（見 §1）：

```
data/extracted/nonprofit/*.json      132 份財報的區段頁碼、數字、附註原文、issues
data/extracted/public_kindergartens.csv    22 所市立幼兒園 × 3 年度
data/extracted/pdf_survey.csv        162 份 PDF 的頁數與文字層統計
data/extracted/text_quality.csv      公校 11,232 頁的 PUA 亂碼比例
公校決算書 15 冊                      分基金 → 頁段（切割靠頁尾代號）
data/processed/compliance_findings.csv     法遵檢核結果與其引用的附註條文
docs/competition/命題文件-教育局.md         題目本身
```

## 3. 三個設計決定

### 3.1 兩種頁碼分開存

這是**已經犯過一次**的錯。抽取結果記的 `page` 是**文件自己印在頁尾的頁碼**
（1-based）；PyMuPDF 的 `page.number` 是 0-based。混用會讓每一筆引用差一頁。

驗證方式是打開 PDF 看：N01 安溪 113 學年度資產負債表在 PyMuPDF index **4**，
頁尾印著 **N01-5**，抽取記 **5**。所以：

```sql
page_start / page_end        -- 印在頁尾的頁碼，稽查員看到的就是這個
pdf_index_start / pdf_index_end  -- PyMuPDF 的 0-based index，開檔案才用
```

公校端的語意又不一樣：頁尾 `13601-4` 的 `4` 是**該分基金內**的第 4 頁，
不是冊內頁次。所以公校的 `page_label` 明講是「PDF 第 N 頁（頁尾代號 13601）」。

### 3.2 空白維持 NULL

`facts.value` 可以是 `NULL`，意思是**空白／未編列**，不是 0。
這是 CLAUDE.md 的鐵則在索引層的落實：業務發展費預算欄空白代表未編列預算
（一項稽查發現），填 0 等於對真實機構謊稱編列了零元。

查詢結果一律附 `is_blank` 與 `blank_means`，呼叫端無從誤會。

### 3.3 索引知道自己不知道什麼

`coverage` 表是刻意加的。全市 1,213 筆登記（1,149 所實體園）中只有 **60 所**
有公開財報；其餘 **94.8% 在這個索引裡沒有任何財務文件**，包含全部私立園。

零命中時 `retrieve()` 回傳的不是空陣列，而是：

> 索引中查無相符資料。全市 1,213 園有 94.8% 沒有公開財報，
> 查不到代表**資料不足**，不代表低風險。

## 4. 中文檢索：用語料自己當字典

FTS5 的 `trigram` 分詞器做字元層級子字串比對，中文不需要斷詞字典。
代價是**整句話當片語丟進去幾乎永遠 0 命中**——使用者問
「附註二關於人事費不得流出的原文」，語料裡寫的是「人事費不得流出」。

解法刻意不引進斷詞套件（多一個字典就多一個會和語料不一致的地方），
而是**用語料自己當字典**：對問句的子字串由長而短探測，
「在語料裡查得到」就是詞，查不到就不是。

```
Q: 附註二關於人事費不得流出的原文
   查詢詞: ['人事費不得流出']          ← 探測出來的，不是猜的
   命中 8（原文 4／欄位 4）
   · 附註二(十)1.(3)：人事費不得流出。
   · N07北大_113學年度財務報告.pdf p.11-14  法遵檢核「人事費不得流出」結果：通過
```

`retrieve()` 會把用過的詞放進 `terms` 回傳——**公開它，稽查員才能用同樣的
字串自己複現同一次檢索**。這是語意改寫做不到的事。

單次查詢 3–10 ms。

## 5. 怎麼用

```bash
python run.py doc-index                      # 建索引
python run.py doc-index -- --rescan          # 重掃 15 冊公校決算書（慢）
python run.py doc-index -- --query 業務發展準備金
python run.py doc-index -- --locate 安溪 --year 113
```

HTTP：

```
GET /api/docsearch?q=資遣費準備金&institution=安溪&year=113
GET /api/docindex/locate?institution=安溪&year=113
GET /api/docindex/facts?institution=安溪&year=113&field=資遣費
GET /api/docindex/coverage
```

Python：

```python
from smart_watchdog.docindex import schema, search
conn = schema.connect()
for r in search.locate(conn, institution="安溪", year=113):
    print(r.kind, r.citation())
# 資產負債表       N01安溪_113學年度財務報告.pdf p.5
# 附註二 重大會計政策 N01安溪_113學年度財務報告.pdf p.11-14
```

  從問句解析出來是下一步，而那一層**可以**用模型——因為它產生的是查詢條件，
  不是證據。
