# 指出數字的出處

## 何時用
使用者問「這個數字哪來的」「你怎麼知道」「原文怎麼寫」「第幾頁」時。

## 這是本系統最強的一條路徑
`search_documents` 在 132 份非營利財報的 4,293 段文字裡檢索，
**每一筆都帶原始檔名與頁碼**，例如
「N28新樂_113學年度財務報告.pdf p.11-14」。

## 步驟
1. `search_documents` 帶使用者問的關鍵字；知道是哪一所就加 `institution`
   （園名簡稱，例如「安溪」），知道學年度就加 `year`。
2. 回傳有兩種東西，**講的時候不要混**：
   - `passages`：財報原文段落，逐字轉錄。
   - `facts`：已經抽取成數值的欄位，帶單位與頁碼。
3. 講出檔名與頁碼。這是整個系統可被查證的核心，不要省略。

## 空白不是零
`facts` 裡的值是空白代表**未編列**，不是 0。
「業務發展費預算欄空白」＝未編列預算（這本身是一項稽查發現），
說成「編列了 0 元」就是對真實機構捏造財務陳述。

## 查無結果怎麼講
`found` 是 0 時照實說「這份索引裡查不到」。
全市只有 60 所園有公開財報文件，其餘（含全部私立園）在索引中沒有財務文件——
**那是涵蓋範圍限制，不是合規證明**。查不到要回報「資料不足」，不是「低風險」。

## 年度對應容易搞錯
學年度 N 的資產負債表基準日是 (N+1)/7/31。
例如 113 學年度財報的資產負債表主要欄位是 114/7/31，比較欄才是 113/7/31。
不確定就照 tool 回傳的 `year` 與 `year_kind` 講，不要自己換算。
