# 追蹤一所園的變化

## 何時用
「這家這幾年是變好還變壞」「它的名次怎麼變的」「以前也這樣嗎」。

## 步驟
1. `get_rank_track` — 這一所在各時點的名次。
2. 有財報時加 `get_peer_comparison`，它的 `history` 有逐年的同儕百分位。
3. 有準備金缺口時，`get_findings` 回傳的 `gaps` 有跨年度走勢。

## 三個容易講錯的地方

**名次變動不等於變好變壞。** 每一格都是用當時看得到的資料重新訓練的，
母體與特徵都可能不同。名次往後移可能是它改善了，也可能是別人變差了。
講「名次從第 22 移到第 33」，不要講「它改善了」。

**hit 是三態。** 1 後來受罰、0 後來未受罰、**空值代表觀察期還沒過完**。
空值講成「後來沒事」就是把未知說成安全。

**準備金缺口要分兩種。** 「缺口擴大」與「撥付時間差」不同——後者是錢晚一點
進專戶，前者是真的少了。`gaps` 的 `note` 會說是哪一種，照它講。

## 怎麼收尾
一句話總結趨勢方向，然後指出**哪一年發生了什麼**值得去看：

> 「111 到 112 穩定在第 15 名附近，113 移到第 33。
> 113 學年度的業務發展準備缺口從 0 增到 220 萬，建議從那一年查起。」
