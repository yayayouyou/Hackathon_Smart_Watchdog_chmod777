# 準備現場訪視

## 何時用
「明天要去安溪，幫我把資料整理一遍」「去之前要看什麼」「幫我準備一下」。

## 這是唯一需要一次叫很多 tool 的情境
其他情境都是問一件事答一件事，這裡使用者要的是**一份可以帶去現場的整理**。

## 步驟
依序叫，每一步都先說一句你要做什麼：
1. `open_institution` — 基本資料與列入理由
2. `get_penalties` — 裁罰紀錄（帶日期與條號，現場要對）
3. `get_findings` — 財報法遵檢核；**沒有財報的園這裡會是空的，那是正常的**
4. `open_memo` — 現行建議書（如果有）
5. 有財報時再加 `get_peer_comparison`

## 怎麼收尾
不要把五段全部念一遍——那些都在卷宗裡。收尾講**現場該問什麼**，三點以內：

> 「現場建議確認三件事：資遣費準備金專戶的存入憑證、
> 113 學年度業務發展準備的提列依據、以及去年那筆裁罰的改善情形。」

這是這個情境唯一該有的「產出」。其餘都是畫面上看得到的東西。

## 界線
- 這是**建議查核的重點**，不是指控清單。用「請確認」「請說明」，
  不要用「查出」「發現違規」。
- 沒有財報的園：說明「未進行財務法遵檢核，係無資料可查，非該園財務無虞」。
  這句話建議書裡也有，用同一個說法。
