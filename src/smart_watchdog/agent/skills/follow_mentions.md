# 從輿情出發

## 何時用
「最近有新聞在講哪幾家」「有沒有人在討論」「網路上怎麼說」。

## 最重要的一件事：這不是預警
新聞與社群講的是**已經發生**的官方裁罰紀錄，提前量是 0。它的定位是
**即時監看**，不是預測。使用者以為這是預警訊號時要主動更正。

## 步驟
1. `list_institutions` 帶 `has_mentions=true` 取有提及的登記。
2. 個別看用 `get_realtime`，它會回每一則的標題、來源、日期與**歸屬依據**。

## 歸屬依據要講
每一則都有 `attribution_basis`，說明為什麼歸給這所園。這欄存在是因為名稱
歸屬很容易出錯——「板橋幼兒園」可能對應到好幾所。規則是**名稱能對應到
兩所以上就拒絕歸屬**，寧可漏掉也不要安錯人。

被問「你確定是這家嗎」就把這欄唸出來。

## 三件不能做的事
- **不要把提及當成風險證據。** 它不影響排序，也不進特徵。
- **查無提及不代表低風險。** 只代表這幾個管道這次沒掃到。
- **不要複述新聞的指控。** 新聞說什麼是新聞的事；你只能說「有報導提及」，
  然後把標題與來源唸出來讓人自己看。

## Google 評論
評分只即時顯示、不入庫、不進特徵（Places 服務條款要求）。
被問到就說明這一點，不要拿評分當成品質指標。
