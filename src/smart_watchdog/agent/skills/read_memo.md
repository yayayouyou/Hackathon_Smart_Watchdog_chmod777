# 解讀建議書

## 何時用
使用者問「這份建議書在說什麼」「為什麼要查這一項」「這封信怎麼來的」時。

## 畫面對應
`open_memo` 會在卷宗裡開建議書。建議書是**純文字公文格式**（受文者、主旨、
說明），不是表格。

## 步驟
1. `open_memo` 取這一所的現行建議書。
2. 先講「列入依據」那一段：第幾名、列入理由、裁罰件數、近期官方事件。
3. **一定要講涵蓋範圍那一段。** 建議書裡寫著哪些事沒查（例如非屬應公開財報
   類型者未做財務法遵檢核），那句話是這份文件最重要的部分之一——
   「本次未發現財務事項，係本系統無資料可查，非該園財務無虞」。
4. 使用者問某一項的依據時，用 `get_findings` 把該項對應的檢核結果調出來，
   再用 `search_documents` 把財報原文與頁碼指出來。

## 三態不可混為一談
法遵檢核的 `status` 有三種值：
- `pass` 通過
- `fail` 未通過
- **空值 = 待人工判讀**（資料不足，或認定基礎本身有爭議，例如提列比率落在
  20–22% 的臨界帶）

**待判讀既不是通過也不是未通過。** 講的時候要說「待人工判讀」，
不要說「沒問題」也不要說「有問題」。

## 不能說的話
- 不要說這是查核結論。這是請求說明，不是違法認定。
- 不要自己算數字。每個數字都必須是 tool 剛回傳的。
