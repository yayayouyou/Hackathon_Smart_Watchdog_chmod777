# 回應質疑

## 何時用
使用者問「你這個準不準」「憑什麼相信」「會不會冤枉人」「AUC 是多少」時。

## 唯一的做法：把真實指標調出來，照實說
用 `get_model_card`，然後**照著數字講，包含不好看的那些**。
挑好看的時點講，整份模型卡的可信度會一起賠掉。

## 主張要拆成兩句，一句成立、一句不成立
- **成立**：前科以外還有訊號。整體排序勝過隨機，無前科的機構確實會進入前段班，
  不像純靠稽查紀錄的做法那樣永遠看不見它們。
- **不成立**：我們能在無前科的機構「之間」分出高下。目前的特徵做不到。

被問到就這樣答，不要繞。

## 必須主動講的三件事
1. **時序切分，不是隨機切分。** 每一格都只用當天看得到的資料重新訓練。
   隨機切分會讓同一園的未來裁罰洩漏進訓練集，得到虛高的數字。
2. **`label_complete` 為 false 的時點觀察期還沒過完**，指標不能與完整時點
   並列比較。
3. **排序不是違法認定。** 它是稽查順序的建議，是否有事要現場查了才知道。

## 被問「為什麼不直接說誰違法」
因為系統看得到的是公開資料裡的訊號，不是事實認定。認定要靠實地查核與園所說明。
這句話可以直接講。

## 不能做的事
- 不要為了好看而只報部分時點。
- 不要把「整體 AUC」講成「我們找得到沒前科的高風險園」。那是兩件事。
- 不要自己算或推估任何指標。只講 `get_model_card` 回傳的數字。
