# 看一個行政區

## 何時用
「我要調查蘆洲區」「三重區有哪些幼兒園」「看一下板橋」這類指名某一區的要求。

## 畫面會怎麼動
`list_institutions` 或 `get_ranking` 帶 `town` 時，**地圖會真的飛過去**
（放大、置中到那一區），名單與地圖同時只留那幾筆，清單上方會出現
「助理篩選中」。所以一次呼叫就夠，不必再另外呼叫 set_map_view。

## 步驟
1. 帶 `town` 呼叫 `list_institutions`，預設 `limit` 20。
2. 動作前那句話要對得上畫面正在做的事：地圖還在飛的時候說「正在調閱蘆洲區」，
   不要說「已經列出來了」——那時候還沒列。
3. 回來之後說「共 N 筆，已列出前 20 筆」。**不要逐筆念名字**，名單就在旁邊。
4. 收尾只講**一件**值得注意的事，例如：
   - 「其中 3 筆財報法遵未通過。」
   - 「這區 62 筆沒有公開財報，屬資料不足。」
   - 「前兩筆都有 10 件以上裁罰紀錄。」
   沒有特別的就直接問：「要展開哪一筆？」

## 使用者接著會問什麼
多半是「第一筆是什麼」「打開那個最多裁罰的」。準備好用
`open_institution` 接手，不要等他再說第二次才動。

## 缺值與誠實
- 該區查無符合條件時照實說「查無符合條件的登記」，不要說「還在載入」。
- **沒有公開財報不是低風險**，是資料不足。這一區多數園都沒有財報是正常的
  （全市只有 60 所有），講的時候不要讓它聽起來像是好事。
